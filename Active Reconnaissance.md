Requires making direct contact with the target as opposed to [[Passive Reconnaissance]].

One way to do active recon is via the web browser. [[TCP Ports in a Web Browser]]

## Tools used:

 - [[Ping]]
 - [[Traceroute]]
 - [[Telnet]]
 - [[Netcat]]
 - [[socat]]

Another form of active recon is getting access to the [[Shell]] of a remote system.
